# Design boundary

CNP701 carries the LC72130 control bus and display-board power/control connections. CNP702 carries tuner status, RDS data and filament-related connections. Only the signals already assigned in the current prototype are mapped to ESP32 GPIOs; power, filament and not-yet-decoded signals remain identified as Sony-side connections.

For the PCB test board

1.  The CNP701 (from mainboard) will be connected into a new connector PCB701-IN.

2.  The CNP702 (from mainboard) will be connected into a new connector PCB702-IN.

3.  PCB Test board connector PCB701-OUT to connect to CN701 (front panel).

4.  PCB Test board connector PCB702-OUT to connect to CN702 (front panel).

PASS THROUGH OPTIONAL == selectable option to passthrough a signal to the original sender/receiver (eg. CN701 pin 1 to CNP701 pin 1) or redirect the signal to the ESP32 GPIO (eg CNP701 pin 1 to GPIO x via IC)

# 4. Level conversion boundary

The five ESP32-to-Sony signals are 3.3 V GPIO outputs and require conversion to the Sony 5 V logic domain using the selected SN74AHCT125N output buffers. The three Sony-to-ESP32 control-bus signals require a verified 5 V-to-3.3 V input stage before connection to the ESP32.

| **Path** | **Signals** | **Required interface** |
|:--:|----|:--:|
| Sony → ESP32 | CE, CLK, DATA, BLN, MUTE | 5 V-tolerant 3.3 V input buffer or correctly sized divider; confirm Sony HIGH level before final wiring |
| ESP32 → Sony | D-IN, AST, ST, SI/SIG, RDS-C, RDS-D | SN74AHCT125N powered from +5 V; 3.3 V GPIO into A, 5 V output from Y |
| Power / VFD | +5 V, GND, −30 V, F, F | Remain Sony-side. Only +5 V and GND are used by the level-conversion circuitry; −30 V and filament lines stay isolated from ESP32 logic |

In total there are 5 channels to step DOWN to 3.3v ,and there are 6 channels to step up to 5v.
